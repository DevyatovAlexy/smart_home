# Система управления умным домом

Учебный локальный прототип на Python. В браузере можно управлять виртуальными светильниками и обогревателем, изменять показания датчиков, включать сценарии и просматривать журнал событий. Реальные устройства не подключаются.

## Запуск

Требуется Python 3.10 или новее. Сторонние пакеты не нужны.

```bash
python app.py
```

Откройте [http://127.0.0.1:8765](http://127.0.0.1:8765) на том же компьютере. Для остановки сервера нажмите `Ctrl+C` в терминале.

При первом запуске создаётся локальная база `smart\_home.db`. Для выбора другого порта используйте `python app.py --port 8766`.

## Возможности

* Ручное переключение света и обогревателя.
* Виртуальные датчики температуры, движения и протечки.
* Сценарии "Дома", "Никого нет" и "Ночь".
* Автоматическое включение света по движению и управление обогревом по двум порогам температуры.
* Сигнал протечки, который работает независимо от переключателя обычных правил.
* Сохранение состояния и журнала событий в SQLite.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Проект предназначен для локальной демонстрации. В нём нет учётных записей и защиты для доступа из внешней сети.
